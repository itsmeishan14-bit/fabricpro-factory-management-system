# 🏭 FabricPro Factory Management System

A full-stack web application designed to streamline operations in small to medium-scale manufacturing units. FabricPro helps factory owners and workers manage daily tasks, track productivity, and improve workflow efficiency.

## 🚀 Features

- 🔐 Secure Login System (Admin & Worker)
- 📊 Dashboard for performance tracking
- 📦 Task submission & management
- 🧾 Material request system
- 📝 Leave request system
- 📈 Productivity tracking
- 💾 MySQL database integration
